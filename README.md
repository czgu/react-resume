# Charlie's Resume

A React-based resume with PDF export functionality. You can reuse this resume by replacing the `src/data` folder with your own data since the data and view are separate.

## Setup

```sh
yarn install
yarn start
```

## Export to PDF

Click the "Download PDF" button in the top-right corner of the page. The generated PDF will have:
- Clickable links (email, GitHub, LinkedIn)
- Selectable text
- Proper A4 sizing

## Build

```sh
yarn build
```

## Run Tests

```sh
yarn test
```
